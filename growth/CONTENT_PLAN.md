## 2. On-Page Structure & Content Architecture

Every game page follows a unified, search-engine-readable content architecture:

```
[Breadcrumbs: Home > Category > Game Title]
<H1> [Game Title + Animal Mascot]
<p> [Tagline & Core Value Hook]
[Playable Game Container - 60 FPS Canvas / React Interactive Viewport]
[How to Play Button -> Opens GameIntroModal with 3-Step Illustrated Guide]
[Controls & Shortcuts Section (H2): Desktop Keyboard/Mouse vs Mobile Touch]
[About the Game (H2): Narrative Background, Mascots, and Gameplay Setting]
[Key Game Features (H2): 5 Bulleted Verified Technical Features]
[Related Animal Games Collection: 4 Direct Visual Links to Complementary Titles]
[Schema.org JSON-LD: WebApplication + VideoGame Rich Snippets]
```

This ensures that:
1. Players immediately interact with the game without scrolling past thousands of words of spam text.
2. Search engines, AI crawlers, and accessibility screen readers receive comprehensive semantic text describing the game rules, controls, and features.
